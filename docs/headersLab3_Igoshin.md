## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX

#### Что такое Markdown
Markdown — это лёгкий язык разметки для оформления README-файлов, документации, отчётов. Он читается как в сыром виде, так и после рендеринга.

#### Где применяется
Markdown используется в веб-разработке, блогах, документации, системах контроля версий, заметках, презентациях.

#### Зачем нужен разработчикам
Для быстрого написания документации, README, комментариев без сложных редакторов. Экономит время и обеспечивает единообразие.
