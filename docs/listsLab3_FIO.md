## Как создать репозиторий

### Подготовка структуры

**Создать папку проекта со следующей структурой:**

*Файл README.md для описания проекта*

*Папка src/ для хранения исходного кода*

*Папка docs/ для документации*

*Файл .gitignore для исключения ненужных файлов*

### Настройка репозитория

Инициализировать Git-репозиторий

```bash
git init
```

Настройка репозитория

Добавить все файлы в staging area

```bash
git add .
```

Проверить статус изменений

```bash
git status
```

Создать первый коммит с описанием

```bash
git commit -m "Initial commit: базовая структура проекта"
```

### Работа с удалённым репозиторием

Настройка удаленного репозитория

```bash
git remote add origin <url>
git push -u origin main
```
